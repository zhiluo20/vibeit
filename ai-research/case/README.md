# 从公开蛋白结构到可复核的距离图

这个小包对应宣传册中的 **1A3N 公开结构分析示例**。问题是：**蛋白质中编号相隔很远的两个氨基酸，在三维空间中也一定很远吗？**

1A3N 是人脱氧血红蛋白的公开实验结构，采用 X 射线衍射测定；它不是本软件预测出来的结构。包内数据沿用原示例的固定快照，无须重新下载或生成数据。

## 你可以得到什么

1. 读取真实 PDB 结构及已选取的 Cα 原子坐标。
2. 计算 B 链每两个 Cα 之间的空间距离，得到完整距离表和热图。
3. 比较不同距离阈值下的几何接近计数，保留计算规则及结果。
4. 打开三维结构文件查看器，旋转、缩放并查看整体结构。

原应用示例中，AI 智能体协助创建和修改分析代码，研究者在意码工坊中运行并检查输出。本小包将同一组固定输入整理为独立脚本和笔记本，并于 2026-10-30 在本机 Python 重新运行、核对；它不代表一次新的移动设备实测。

## 如何运行

保持整个文件夹结构，不要单独移走数据文件。选择以下一种方式：

- **笔记本：**打开 `1A3N-analysis.ipynb`，从上到下运行代码单元。
- **Python脚本：**在本文件夹执行 `python analysis.py`。

需要 NumPy、pandas 和 matplotlib，依赖列在 `requirements.txt`。先确认所选环境中具备这些包；脚本不自动安装或下载任何数据。在意码工坊中可导入整个文件夹，再打开笔记本运行。

数值分析和热图使用本地输入。`results/structure-view.html` 内嵌真实 PDB 坐标，三维显示库从 3Dmol.org 加载，因此首次打开三维查看器需要联网；该查看器不参与距离矩阵的计算与核验。

重复运行只覆盖 `results/` 中的同名输出，不修改输入。

## 已运行的核对结果

- B 链包含 **145 个 Cα**，矩阵为 **145 × 145**，对称、有限且对角线为零。
- 采用 **PDB 编号间隔 >2、距离严格小于阈值、每对只计一次 `i<j`** 的规则，6、8、10 Å 下分别得到 **174、390、920** 对。
- B 链 Glu7 与 Ala129 的 Cα 距离为 **5.024620483181 Å**；两者 PDB 编号相差 122。
- 新算矩阵与原示例八位小数导出矩阵的最大差异约 **5 × 10⁻⁹ Å**，来自导出舍入；本次按相同精度导出的 CSV 与原导出文件**逐字节一致**。输入 PDB 与 CSV 中所选原子坐标逐项匹配。

计数随选定阈值而变化。这里的距离是几何指标，不等同于化学键、结合强度或生物学功能；不能据此直接得出治疗、突变效应或临床结论。

本脚本中的哈希、原子数和参考值用于复现这一固定示例。如果分析其他结构，应重新选择和核对输入、链、原子与分析规则，不能修改输入来迎合这里的参考计数。
