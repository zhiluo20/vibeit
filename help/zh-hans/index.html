Vibeit 使用手册

通过真实 App 截图和清晰步骤，一次学会一个任务。

从常见任务开始

Section titled “从常见任务开始”
  • 第一次运行 Python — 运行一个笔记本单元和一个 Python 脚本，并找到输出结果。
  • 登录 Codex 并加载模型 — 连接 Codex 账号，并从该账号实际可用的模型中进行选择。
  • 选择模型与推理强度 — 根据任务选择推理强度，并理解它与界面主题无关。
  • 配置 Hugging Face Token — 保存 Hugging Face Token，并使它在新启动的 Python 内核中生效。
  • 克隆并打开仓库 — 把 GitHub 仓库克隆为本地可编辑的工作副本。
  • 使用密码连接 SSH 服务器 — 保存服务器配置、核验主机密钥并打开远程文件。
