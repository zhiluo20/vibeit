Ce que vous allez faire

Section intitulée « Ce que vous allez faire »

Comprenez l’ordre d’exécution, arrêtez une tâche longue et repartez d’un état Python neuf.

Avant de commencer

Section intitulée « Avant de commencer »
  • Un abonnement Standard ou Pro actif, ou une période d’essai éligible.

Télécharger le projet d’exemple

Point de départ

Section intitulée « Point de départ »
Open a notebook → execution controls

À retenir

Sous iOS/iPadOS 1.0.1, fermez complètement Vibeit puis rouvrez l’app après avoir modifié Environment. Restart Kernel réinitialise la session Python sans recharger ces réglages enregistrés.

Vérifiez le résultat

Section intitulée « Vérifiez le résultat »

Après le redémarrage, recréez les variables en exécutant le notebook dans l’ordre. Une erreur NameError signifie souvent qu’une cellule définissant la variable n’a pas été exécutée.

En cas de problème

Section intitulée « En cas de problème »
  • Pour une erreur NameError, exécutez la cellule qui définit le nom manquant.
  • Pour FileNotFoundError, vérifiez le dossier de travail et la position du dossier data par rapport au notebook.
  • Pour ModuleNotFoundError, vérifiez la disponibilité de la bibliothèque : télécharger un fichier n’installe pas sa bibliothèque Python.
