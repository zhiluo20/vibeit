# 多学科课程扩展：固定交付范围

用户确认：其余七个学科**每个 6 课，中英文各一版**。新增 42 个独立工作流、84 份 notebook；加上现有生物信息学，共 48 课、96 份 notebook。课程面向有 Python 基础的本科生。

| 学科 | 六课学习路径 | 冻结的输入及解释边界 |
|---|---|---|
| 数据科学与机器学习 | Iris 数据审计 → 标准化 PCA → 训练/测试与 kNN → Wine 聚类 → 共享单车回归 → 滚动预测评估 | UCI Iris、Wine、Bike Sharing；测试集不参与标准化、调参；聚类不证明真实类别；预测不代表因果。 |
| 数学与统计 | 数值微积分 → 求根与误差 → 线性代数及病态问题 → Monte Carlo → Bootstrap → 置换检验与多重校正 | 可验证的解析模型、参考物理常数及 Iris 实测数据；数值误差与采样不确定性分开，方便样本不自动代表总体。 |
| 物理 | 非线性单摆 → 阻尼与共振 → 空气阻力下抛体 → 热扩散 → GW150914 信号处理 → 黑体辐射 | 透明数值模型、NIST CODATA 常数、GWOSC 冻结应变；模型轨迹不冒充实验，滤波图不独立证明探测显著性。 |
| 化学 | 分子式与组成 → 分子图 → 计算构象的三维几何 → 酸碱滴定 → 水的饱和蒸气压 → 光谱校准模型 | PubChem 计算性质和结构、IAPWS 参考关联式、标注清楚的教学模型；计算构象不冒充实验结构；描述符不等同于药效。 |
| 工程 | 实测能耗审计 → 能耗回归 → 时间序列滤波 → 梁有限元 → RC 电路 → PID 控制 | UCI Appliances Energy Prediction、明确参数的设计模型；Wh 与 W 区分；数字控制仿真不等于硬件验收。 |
| 经济与金融 | 实际增长 → 通胀与实值 → 调查年份与不平等 → 汇率收益 → 组合方差 → 尾部风险与重采样 | World Bank 及 ECB；缺失年份不编造；价格/收益单位明确；历史结果不作为未来投资承诺。 |
| 人文与社会科学 | 文本清洗 → 长度控制的词汇多样性 → KWIC → 人物共现图 → TF-IDF/SVD → 社会指标探索 | 公版小说文本与 World Bank；词频、共现、降维和国家层面相关性都需要回到文本或调查设计解释。 |

数据制作阶段保留原始响应、日期、版本/发布号、SHA-256、许可及转换步骤。学生只需要一个 `.ipynb`：快照压缩进 metadata，核心无网络、无 AI 服务配置、无安装单元。使用当前应用包目录验证过的标准库、NumPy、Pandas、SciPy、Matplotlib、NetworkX、py3Dmol 和 IPython；联网扩展使用 Requests。研究限定许可或条件冲突的数据源不用于官网课程（例如 UCI Air Quality 的附加研究限定与通用许可存在冲突，工程课程使用另外核验的能耗数据）。

每课保留 Gallery 风格 HTML 首卡、学习目标、来源与输入审计、参数、分步分析、至少三类实算图、带单位图注、独立校验、结果导出、两项自主练习与答案、两项可选 AI 练习及人工验收。网页保持现有产品配色、共享 header、callout 与静态代码高亮。

执行顺序：通用学科清单与生成器 → 原始数据冻结 → 七个学科各六课的计算与双语教学内容 → 84 份离线执行 → 独立数值/失败场景核验 → 目标应用及桌面/手机网页验收 → 下载哈希核对及可审核 PR。完成标准是七个学科均有六个通过验证的工作流，不以先完成的学科代替完整范围。
