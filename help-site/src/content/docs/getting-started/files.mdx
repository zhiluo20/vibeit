## Check the result

Use the notebook’s share/export control and choose the required format and destination in the system sheet. Reopen the exported file to check it.

## If it does not work

- If a file is missing, return to the file browser and confirm which workspace or folder is active.
- If a run fails, read the first error line and check that earlier cells and required packages are available.
