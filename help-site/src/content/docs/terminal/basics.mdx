## Check the result

A remote terminal sends commands to the server. Local iPad commands and available packages differ from a desktop or Linux shell.

## If it does not work

- Tap the terminal surface to give it keyboard focus. Use a long press for the system selection menu.
- A local iPad shell and a remote server shell do not have identical commands or packages. Check which terminal is active.
