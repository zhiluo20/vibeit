## 核对结果

导出笔记本，或通过 Python 写入结果文件，然后确认文件已经出现在项目中。

## 如果没有成功

- 出现 NameError 时，先运行定义该名称的单元。
- 出现 FileNotFoundError 时，检查工作目录，并把 data 文件夹与笔记本放在正确的相对位置。
- 出现 ModuleNotFoundError 时，检查包是否可用；下载文件并不等于安装了 Python 包。
