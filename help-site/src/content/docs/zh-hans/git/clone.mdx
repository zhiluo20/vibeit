## 你将完成什么

把 GitHub 仓库克隆为本地可编辑的工作副本。

## 开始前准备

- 有效的 Pro 订阅。第三方 AI 订阅和 API 额度需要单独准备。
- 能够连接本教程所用服务或下载资源的网络。

[下载教程示例项目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 核对结果

从 Files 区域打开源代码管理，检查分支和历史，再开始编辑文件。

## 如果没有成功

- Commit 记录本地历史，Push 才会发送到远程。先确认失败的是哪一步。
- 推送被拒绝时，检查远程改动和账号权限，不要把强制推送当作常规修复方式。
- 发生冲突时，先保留副本并检查相关文件，再决定如何处理改动。
