## 你将完成什么

在 Vibeit 中连接已经配置好的 Cloudflare Access SSH 应用。

## 开始前准备

- 有效的 Pro 订阅。第三方 AI 订阅和 API 额度需要单独准备。
- 能够连接本教程所用服务或下载资源的网络。
- 可访问的 SSH 服务器、主机地址与端口、用户名，以及你有权使用的认证方式。

[下载教程示例项目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 从哪里进入

<div className="entry-path">Add Remote Host → Connection → Cloudflare Access</div>

:::note[请留意]
Access 授权与 SSH 认证是两项独立检查。Access 会话过期后需要重新登录。
:::

## 核对结果

除非服务配置支持更多并发，否则保留默认并发数。保存、核验主机密钥，并实际连接文件目录。

## 如果没有成功

- 连接超时时，检查地址、端口、网络路径和服务器状态。
- 认证失败时，检查用户名及匹配的密码或私钥。
- 主机指纹变化时，通过可信渠道核实后再更新保存的指纹。
