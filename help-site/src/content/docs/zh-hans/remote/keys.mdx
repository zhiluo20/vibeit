## 你将完成什么

配置与服务器已授权公钥对应的私钥。

## 开始前准备

- 有效的 Pro 订阅。第三方 AI 订阅和 API 额度需要单独准备。
- 能够连接本教程所用服务或下载资源的网络。
- 可访问的 SSH 服务器、主机地址与端口、用户名，以及你有权使用的认证方式。

[下载教程示例项目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 从哪里进入

<div className="entry-path">Add or Edit Remote Host → Authentication</div>

:::note[请留意]
私钥文件应放在独立且不共享的本地文件夹中，避免进入 Git 仓库或共享导出。使用 Vibeit 支持的 Ed25519 或 RSA 私钥格式。
:::

## 核对结果

核验主机指纹后连接并打开远程目录。若被拒绝，检查用户名和服务器上授权的公钥是否匹配。

## 如果没有成功

- 连接超时时，检查地址、端口、网络路径和服务器状态。
- 认证失败时，检查用户名及匹配的密码或私钥。
- 主机指纹变化时，通过可信渠道核实后再更新保存的指纹。
