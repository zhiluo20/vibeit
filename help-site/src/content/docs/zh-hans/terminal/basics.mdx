## 核对结果

远程终端把命令发送到服务器。iPad 本地终端的命令和依赖与桌面或 Linux Shell 不完全相同。

## 如果没有成功

- 点击终端窗口使其获得键盘焦点，长按打开系统选择菜单。
- iPad 本地终端与远程服务器终端的命令和依赖不完全相同，请确认当前使用的位置。
