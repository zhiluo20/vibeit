## 你将完成什么

连接 Codex 账号，并从该账号实际可用的模型中进行选择。

## 开始前准备

- 有效的 Pro 订阅。第三方 AI 订阅和 API 额度需要单独准备。
- 能够连接本教程所用服务或下载资源的网络。
- 能够使用 Codex 服务的 OpenAI 账号。

[下载教程示例项目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 核对结果

需要更新列表时使用 Refresh Models。保存设置；希望由 Codex 驱动助手时，选择 Use This Provider。

## 如果没有成功

- 配置后没有使用该服务时，选择 Use This Provider，并检查当前启用标记。
- 出现登录或密钥错误时，先修复服务配置，再用简短请求重试。
- 服务选项可能受 App Store 地区、订阅及服务商账号权限影响。
