## 你将完成什么

保存 Anthropic API Key，并选择 Claude 模型。

## 开始前准备

- 有效的 Pro 订阅。第三方 AI 订阅和 API 额度需要单独准备。
- 能够连接本教程所用服务或下载资源的网络。
- Anthropic API Key，以及可用的 API 权限或额度。

[下载教程示例项目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 从哪里进入

<div className="entry-path">Settings → AI → Claude</div>

## 核对结果

保存配置并选择 Use This Provider。若测试提示 Invalid key，请更换密钥后重试。

## 如果没有成功

- 配置后没有使用该服务时，选择 Use This Provider，并检查当前启用标记。
- 出现登录或密钥错误时，先修复服务配置，再用简短请求重试。
- 服务选项可能受 App Store 地区、订阅及服务商账号权限影响。
