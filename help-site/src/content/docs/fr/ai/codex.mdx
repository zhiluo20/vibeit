## Ce que vous allez faire

Connectez votre compte Codex et choisissez parmi les modèles réellement disponibles pour ce compte.

## Avant de commencer

- Un abonnement Pro actif. Les abonnements aux services d’IA et les crédits API sont distincts.
- Une connexion permettant d’accéder au service ou au téléchargement utilisé dans ce tutoriel.
- Un compte OpenAI disposant d’un accès compatible avec Codex.

[Télécharger le projet d’exemple](/vibeit/help/downloads/vibeit-tutorials.zip)

## Point de départ

<div className="entry-path">Settings → AI → Codex</div>

## Vérifiez le résultat

Utilisez Refresh Models pour actualiser la liste. Enregistrez les réglages, puis choisissez Use This Provider lorsque vous souhaitez utiliser Codex pour l’assistant.

## En cas de problème

- Si le service est configuré mais pas utilisé, choisissez Use This Provider et vérifiez l’indicateur de service actif.
- En cas d’erreur de connexion ou de clé, corrigez la configuration avant de réessayer une courte demande.
- Les services proposés peuvent dépendre de la région App Store, de votre abonnement et des droits de votre compte chez le fournisseur.
