## Ce que vous allez faire

Transmettez la configuration du projet à un nouveau noyau Python et à un nouveau terminal.

## Avant de commencer

- Un abonnement Standard ou Pro actif, ou une période d’essai éligible.

[Télécharger le projet d’exemple](/vibeit/help/downloads/vibeit-tutorials.zip)

## Point de départ

<div className="entry-path">Settings → Environment → Environment Variables</div>

:::note[À retenir]
Sous iOS/iPadOS 1.0.1, fermez complètement Vibeit puis rouvrez l’app après avoir modifié Environment. Restart Kernel réinitialise la session Python sans recharger ces réglages enregistrés.
:::

## Vérifiez le résultat

Le nouveau noyau affiche tutorial.

## En cas de problème

- Si un nouveau jeton ou une nouvelle variable n’est pas visible dans Python, redémarrez le noyau.
- Pour une réponse 401 ou 403, vérifiez le jeton et les autorisations du compte sur la ressource.
- Si le téléchargement réussit mais pas le chargement, vérifiez le format, les bibliothèques requises et la mémoire disponible.
