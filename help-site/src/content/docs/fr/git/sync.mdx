## Ce que vous allez faire

Récupérez les commits distants dans la copie de travail, puis envoyez vos propres commits.

## Avant de commencer

- Un abonnement Pro actif. Les abonnements aux services d’IA et les crédits API sont distincts.
- Une connexion permettant d’accéder au service ou au téléchargement utilisé dans ce tutoriel.
- Un dépôt Git existant. Utilisez le dépôt d’exemple séparé pour vous entraîner.

[Télécharger le projet d’exemple](/vibeit/help/downloads/vibeit-tutorials.zip)

## Vérifiez le résultat

Ouvrez la branche correspondante sur GitHub et contrôlez le message du commit et le contenu des fichiers. Dans un espace de travail distant, Git s’exécute sur le serveur avec les identifiants Git de ce serveur.

## En cas de problème

- Commit enregistre l’historique local ; Push envoie les commits au dépôt distant. Identifiez l’opération qui a échoué.
- Si un envoi est refusé, examinez les modifications distantes et vos droits. N’utilisez pas systématiquement un envoi forcé.
- En cas de conflit, conservez une copie et examinez les fichiers concernés avant d’abandonner des modifications.
