## What you will do

Ask the App Store to refresh an existing subscription entitlement.

## Before you start

- A working internet connection for the service or download used in this tutorial.

[Download the tutorial workspace](/vibeit/help/downloads/vibeit-tutorials.zip)

## Where to start

<div className="entry-path">Settings → Account → Restore Purchases</div>

## Check the result

If no active purchase is found, inspect the offered plans. If Apple shows an active subscription but Vibeit does not, send a report with the version and error message.

## If it does not work

- Restore Purchases uses the Apple Account that made the purchase. An empty restore result does not create a subscription.
- Include the App version, device, steps and exact error message when reporting a problem; omit secrets.
