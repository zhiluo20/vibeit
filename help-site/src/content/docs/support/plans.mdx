## Check the result

After a successful purchase, return to the app and check the active plan. If a trial has ended, choose an available plan or restore a previous valid purchase.

## If it does not work

- Restore Purchases uses the Apple Account that made the purchase. An empty restore result does not create a subscription.
- Include the App version, device, steps and exact error message when reporting a problem; omit secrets.
