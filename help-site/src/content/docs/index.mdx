## Start with a common task

- [Run your first Python code](/vibeit/help/getting-started/first-run/) — Run a notebook cell and a Python script, and recognize their output.
- [Sign in to Codex and load models](/vibeit/help/ai/codex/) — Connect a Codex account and choose from the models available to that account.
- [Choose a model and reasoning effort](/vibeit/help/ai/reasoning/) — Choose an effort level for the task without confusing it with the app theme.
- [Configure a Hugging Face token](/vibeit/help/models/hugging-face/) — Store a Hugging Face token and apply it to a newly started Python kernel.
- [Clone and open a repository](/vibeit/help/git/clone/) — Create a local working copy of a GitHub repository.
- [Connect to an SSH server with a password](/vibeit/help/remote/ssh/) — Save a server profile, verify its host key and open its remote files.
