## 你將完成什麼

保存 Anthropic API Key，並選擇 Claude 模型。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 能夠連接本教程所用服務或下載資源的網絡。
- Anthropic API Key，以及可用的 API 權限或額度。

[下載教程示例項目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 從哪裡進入

<div className="entry-path">Settings → AI → Claude</div>

## 核對結果

保存配置並選擇 Use This Provider。若測試提示 Invalid key，請更換密鑰後重試。

## 如果沒有成功

- 配置後沒有使用該服務時，選擇 Use This Provider，並檢查當前啟用標記。
- 出現登錄或密鑰錯誤時，先修復服務配置，再用簡短請求重試。
- 服務選項可能受 App Store 地區、訂閱及服務商帳號權限影響。
