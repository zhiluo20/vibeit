## 你將完成什麼

連接 Codex 帳號，並從該帳號實際可用的模型中進行選擇。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 能夠連接本教程所用服務或下載資源的網絡。
- 能夠使用 Codex 服務的 OpenAI 帳號。

## 核對結果

需要更新列表時使用 Refresh Models。保存設置；希望由 Codex 驅動助手時，選擇 Use This Provider。

## 如果沒有成功

- 配置後沒有使用該服務時，選擇 Use This Provider，並檢查當前啟用標記。
- 出現登錄或密鑰錯誤時，先修復服務配置，再用簡短請求重試。
- 服務選項可能受 App Store 地區、訂閱及服務商帳號權限影響。
