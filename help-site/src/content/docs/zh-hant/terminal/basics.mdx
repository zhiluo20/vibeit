## 核對結果

遠程終端把命令發送到伺服器。iPad 本地終端的命令和依賴與桌面或 Linux Shell 不完全相同。

## 如果沒有成功

- 點擊終端窗口使其獲得鍵盤焦點，長按打開系統選擇菜單。
- iPad 本地終端與遠程伺服器終端的命令和依賴不完全相同，請確認當前使用的位置。
