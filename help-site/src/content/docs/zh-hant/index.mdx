通過真實 App 截圖和清晰步驟，一次學會一個任務。

## 從常見任務開始

- [第一次運行 Python](/vibeit/help/zh-hant/getting-started/first-run/) — 運行一個筆記本單元和一個 Python 腳本，並找到輸出結果。
- [登錄 Codex 並加載模型](/vibeit/help/zh-hant/ai/codex/) — 連接 Codex 帳號，並從該帳號實際可用的模型中進行選擇。
- [選擇模型與推理強度](/vibeit/help/zh-hant/ai/reasoning/) — 根據任務選擇推理強度，並理解它與界面主題無關。
- [配置 Hugging Face Token](/vibeit/help/zh-hant/models/hugging-face/) — 保存 Hugging Face Token，並使它在新啟動的 Python 核心中生效。
- [克隆並打開倉庫](/vibeit/help/zh-hant/git/clone/) — 把 GitHub 倉庫克隆為本地可編輯的工作副本。
- [使用密碼連接 SSH 伺服器](/vibeit/help/zh-hant/remote/ssh/) — 保存伺服器配置、核驗主機密鑰並打開遠程檔案。
