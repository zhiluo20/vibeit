## 核對結果

在安裝該包的同一個運行環境中測試導入。遠程包屬於所選伺服器解釋器。

## 如果沒有成功

- 新保存的 Token 或環境變量未生效時，重啟核心。
- 遇到 401/403 時，檢查 Token 和資源的帳號訪問權限。
- 下載成功但不能加載時，檢查格式、所需依賴和可用內存。
