## 你將完成什麼

保存 Hugging Face Token，並使它在新啟動的 Python 核心中生效。

## 開始前準備

- 有效的 Standard、Pro 訂閱，或符合條件的試用。
- 能夠連接本教程所用服務或下載資源的網絡。
- 若資源要求身份驗證，需要 Hugging Face 帳號和具有所需權限的 Token。

[下載教程示例項目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 從哪裡進入

<div className="entry-path">Settings → Environment → Hugging Face Token</div>

:::note[請留意]
在 iOS/iPadOS 1.0.1 中，更改“環境”設置後，需要完全關閉並重新打開 Vibeit。Restart Kernel 會重置 Python 會話，但不會重新加載這些設置。
:::

## 核對結果

運行示例。HF_TOKEN present: True 表示核心已讀取 Token；Hugging Face authorization: OK 表示服務已接受授權。受限模型的訪問許可仍需單獨獲得。

## 如果沒有成功

- 新保存的 Token 或環境變量未生效時，重啟核心。
- 遇到 401/403 時，檢查 Token 和資源的帳號訪問權限。
- 下載成功但不能加載時，檢查格式、所需依賴和可用內存。
