## 你將完成什麼

授權 Vibeit 訪問帳號有權使用的 GitHub 倉庫。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 能夠連接本教程所用服務或下載資源的網絡。

[下載教程示例項目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 核對結果

返回 Vibeit，確認 GitHub 顯示的是你打算使用的已登錄帳號。

## 如果沒有成功

- Commit 記錄本地歷史，Push 才會發送到遠程。先確認失敗的是哪一步。
- 推送被拒絕時，檢查遠程改動和帳號權限，不要把強制推送當作常規修復方式。
- 發生衝突時，先保留副本並檢查相關檔案，再決定如何處理改動。
