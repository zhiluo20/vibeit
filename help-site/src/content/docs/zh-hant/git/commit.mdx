## 你將完成什麼

把檢查過的改動保存到倉庫的本地歷史中。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 一個已經存在的 Git 倉庫。練習時使用獨立的教程倉庫。

## 核對結果

點擊 Commit，確認新說明出現在 History 中。這一步記錄本地歷史，還沒有把提交發送到 GitHub。

## 如果沒有成功

- Commit 記錄本地歷史，Push 才會發送到遠程。先確認失敗的是哪一步。
- 推送被拒絕時，檢查遠程改動和帳號權限，不要把強制推送當作常規修復方式。
- 發生衝突時，先保留副本並檢查相關檔案，再決定如何處理改動。
