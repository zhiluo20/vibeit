## 核對結果

導出筆記本，或通過 Python 寫入結果檔案，然後確認檔案已經出現在項目中。

## 如果沒有成功

- 出現 NameError 時，先運行定義該名稱的單元。
- 出現 FileNotFoundError 時，檢查工作目錄，並把 data 資料夾與筆記本放在正確的相對位置。
- 出現 ModuleNotFoundError 時，檢查包是否可用；下載檔案並不等於安裝了 Python 包。
