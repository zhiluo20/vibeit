## 你將完成什麼

配置與伺服器已授權公鑰對應的私鑰。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 能夠連接本教程所用服務或下載資源的網絡。
- 可訪問的 SSH 伺服器、主機地址與端口、用戶名，以及你有權使用的認證方式。

[下載教程示例項目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 從哪裡進入

<div className="entry-path">Add or Edit Remote Host → Authentication</div>

:::note[請留意]
私鑰檔案應放在獨立且不共享的本地資料夾中，避免進入 Git 倉庫或共享導出。使用 Vibeit 支持的 Ed25519 或 RSA 私鑰格式。
:::

## 核對結果

核驗主機指紋後連接並打開遠程目錄。若被拒絕，檢查用戶名和伺服器上授權的公鑰是否匹配。

## 如果沒有成功

- 連接超時時，檢查地址、端口、網絡路徑和伺服器狀態。
- 認證失敗時，檢查用戶名及匹配的密碼或私鑰。
- 主機指紋變化時，通過可信渠道核實後再更新保存的指紋。
