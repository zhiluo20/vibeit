## 你將完成什麼

在 Vibeit 中連接已經配置好的 Cloudflare Access SSH 應用。

## 開始前準備

- 有效的 Pro 訂閱。第三方 AI 訂閱和 API 額度需要單獨準備。
- 能夠連接本教程所用服務或下載資源的網絡。
- 可訪問的 SSH 伺服器、主機地址與端口、用戶名，以及你有權使用的認證方式。

[下載教程示例項目](/vibeit/help/downloads/vibeit-tutorials.zip)

## 從哪裡進入

<div className="entry-path">Add Remote Host → Connection → Cloudflare Access</div>

:::note[請留意]
Access 授權與 SSH 認證是兩項獨立檢查。Access 會話過期後需要重新登錄。
:::

## 核對結果

除非服務配置支持更多併發，否則保留默認併發數。保存、核驗主機密鑰，並實際連接檔案目錄。

## 如果沒有成功

- 連接超時時，檢查地址、端口、網絡路徑和伺服器狀態。
- 認證失敗時，檢查用戶名及匹配的密碼或私鑰。
- 主機指紋變化時，通過可信渠道核實後再更新保存的指紋。
