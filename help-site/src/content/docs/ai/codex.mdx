## What you will do

Connect a Codex account and choose from the models available to that account.

## Before you start

- An active Pro subscription. Third-party AI subscriptions and API credits are separate.
- A working internet connection for the service or download used in this tutorial.
- A Codex-compatible OpenAI account with access to the service.

[Download the tutorial workspace](/vibeit/help/downloads/vibeit-tutorials.zip)

## Where to start

<div className="entry-path">Settings → AI → Codex</div>

## Check the result

Use Refresh Models if the list needs updating. Save the settings, then use Use This Provider when you want Codex to power the agent.

## If it does not work

- If the provider is configured but not used, select Use This Provider and check the active badge.
- For sign-in or key errors, repair the provider configuration before retrying a short request.
- Provider choices can depend on your App Store region, subscription and the provider account.
